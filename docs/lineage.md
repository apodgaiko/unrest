# Source lineage

Unrest contains software derived from
[Intelligent Internet's Zenith](https://github.com/Intelligent-Internet/zenith),
distributed under the Apache License, Version 2.0.

The Apache license is retained in [`LICENSE`](../LICENSE), and [`NOTICE`](../NOTICE)
records the upstream project and copyright attribution.

Unrest is independently maintained by apodgaiko. Since the source import, the
project has changed its package and runtime identity, host setup, validation and
terminal-review behavior, provider configuration, documentation, and release
structure. Git history is the detailed record of modifications.

Unrest is not an official continuation of Zenith, and Intelligent Internet does
not endorse it. The source name is used only for attribution and accurate
provenance.
