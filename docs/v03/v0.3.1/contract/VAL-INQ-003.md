# VAL-INQ-003 — Independent synthesis with dissent

**Surface:** `advance_inquiry`, synthesis provider role, and synthesis artifact.

**Needs:** VAL-INQ-002 branch terminal outcomes.

**Behavior:** Synthesis is a separate operation/identity after fan-out. It
receives the exact question and complete branch denominator, cites each branch
identity/outcome, distinguishes missing/failed evidence, retains minority
dissent and limitations, and cannot change branch records or Mission/workspace.

**Evidence:** Complete, failed, cancelled, contradictory, and all-missing branch
sets; branch/synthesis identity mutation; citation resolution; retained dissent;
and state-byte comparisons.
