# VAL-EVO-002 — Immutable genealogy and complete retention

**Surface:** MCP `add_candidate`, matching library call, artifacts and durable lineage.

**Needs:** VAL-EVO-001.

**Behavior:** Candidate, edit, rebase and retry edges are immutable and acyclic;
each child binds one exact parent/action/content identity. Every admitted,
rejected, rework, failed, cancelled, inconclusive and budget-exhausted attempt,
including cost completeness and dissent, remains in the denominator for the
project lifetime. Retry appends and cannot overwrite/suppress.

**Evidence:** Real branching genealogy, restart, cycle/parent/content mutation,
all outcomes, retry, attempted deletion/suppression, denominator and retention.
