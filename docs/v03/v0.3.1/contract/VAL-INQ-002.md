# VAL-INQ-002 — Structurally read-only concurrent fan-out

**Surface:** configured provider workers, capability policy, subprocess, and artifacts.

**Needs:** VAL-INQ-001.

**Behavior:** One advance fans out direct, evidence, critic, and analogy
branches concurrently in distinct read-only roles. Their available tools and
authority contain no Mission mutation, workspace lease/write/integration,
campaign promotion, or external effect. One branch failure does not erase
other outcomes; concurrency is bounded by Inquiry budget/configuration.

**Evidence:** Real provider run with overlapping monotonic intervals, effective
tool/policy inventory, injected branch failure/timeout, durable outcomes, and
before/after Mission/workspace bytes.

**Scope:** Read-only is structural capability restriction, not an OS sandbox claim.
