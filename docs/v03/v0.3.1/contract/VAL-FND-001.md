# VAL-FND-001 — Accepted six-family runtime foundation

**Surface:** accepted ADR index, normative contracts, bundled assets, installed runtime.

**Needs:** ADR-0300 through ADR-0305 and the complete v0.3.1 implementation.

**Behavior:** Exactly authority, identity, Inquiry, workspace, evolution, and
compatibility are accepted and active. Their ADRs are indexed as accepted and
all operative documents agree; no active text says they are proposal-only,
non-authoritative, unindexed, unimplemented, or forbidden to issue/consume the
records that product code actually supports.

**Evidence:** Scan every normative/accepted entry point, resolve links, compare
the six-family machine registry with installed handlers, and exercise one real
public transition from each family. A status edit without runtime calls fails.

**Fail:** Any seventh family, missing handler, contradictory operative status,
or proposal fixture treated as runtime authority fails closed.
